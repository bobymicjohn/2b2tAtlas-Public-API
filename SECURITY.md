# Security policy

This repository contains public read-only examples. Do not report account credentials, Minecraft session material, private coordinates, infrastructure details, or authentication tokens in a public issue.

If you discover that a public API route exposes write access without authorization, leaks credentials, or discloses material that clearly should not be public, contact the 2b2tAtlas maintainers privately through the contact path on [2b2tAtlas](https://2b2tatlas.com) rather than opening a public proof-of-concept issue.

For ordinary documentation bugs, stale public records, broken links, or example failures, use the public issue templates.
