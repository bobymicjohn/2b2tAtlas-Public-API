# Data and media notice

The MIT license in this repository covers the example code and repository-authored documentation.

Responses from the 2b2tAtlas API describe a historical catalog assembled from multiple sources. Some records link to or preserve third-party screenshots, videos, wiki pages, renders, logos, and other media. Those assets are not automatically licensed under this repository's MIT license.

When consuming or redistributing Atlas records:

1. Preserve record-level `sourceUrl`, `attribution`, `caption`, and evidence fields.
2. Link to the returned `canonicalUrl` or `interactiveUrl` where possible.
3. Review the original source's terms before republishing media files.
4. Distinguish factual metadata from a third party's creative work.
5. Do not represent a historical coordinate as proof of a location's current status.

Questions about a specific Atlas record should include its `apiUrl` or canonical entity URL.
